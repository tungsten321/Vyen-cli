Termux First-Class

Tối Ưu Native Cho Termux Trên Android

Xây dựng bằng 100% JavaScript thuần chạy trên Node >= 22.16 LTS. Vận hành trực tiếp trong môi trường Termux mà không cần quyền root, không cần proot hay glibc wrapper cồng kềnh.

  • ✓ Khởi chạy tức thì trong thư mục $HOME của thiết bị di động
  • ✓ Tận dụng ripgrep hệ thống với cơ chế fallback JS thuần mượt mà
  • ✓ Hỗ trợ đầy đủ tương tác clipboard hệ thống Android
BYOK Freedom

Bring Your Own Key & Tự Do Đa Provider

Loại bỏ hoàn toàn chi phí thuê bao cố định và rủi ro bị khóa chặt vào một nhà cung cấp. Bạn toàn quyền sử dụng API key cá nhân để kết nối trực tiếp với các mô hình tiên tiến nhất.

  • ✓ Tương thích OpenAI, Responses API chuẩn mực và Anthropic Messages
  • ✓ Hỗ trợ suy luận cục bộ ngoại tuyến qua Ollama, vLLM, LM Studio
  • ✓ Tự động khám phá danh mục model linh hoạt qua lệnh /models
Fail-Closed Safety

Bảo Mật Phân Tầng & Workspace Trust

Quyền kiểm soát chặt chẽ với các chế độ Ask / Auto / Read-Only. Xác thực Workspace Trust bằng chữ ký SHA-256 bảo vệ toàn diện các kịch bản shell thực thi.

  • ✓ 8 Hook vòng đời fail-closed (PreToolUse, PostToolUse...) bảo vệ hệ thống
  • ✓ Ngăn chặn hoàn toàn việc rò rỉ credential API ra shell con
  • ✓ Nhật ký kiểm toán audit log định dạng JSONL minh bạch cục bộ
Extensible Power

Subagents & Model Context Protocol (MCP)

Khả năng mở rộng không giới hạn: phân quyền tác vụ cho các Subagent chạy nền độc lập, kết nối công cụ ngoài qua chuẩn Model Context Protocol (MCP) và ghép đôi thiết bị qua /pair.

  • ✓ Quản lý MCP cấp độ user và project (.vyen/mcp.json) với ưu tiên User Deny
  • ✓ Điều phối mạng lưới tác vụ Agent Network và workflow tùy biến
  • ✓ Ghép đôi thiết bị từ xa qua tunnel bảo mật Cloudflare (/pair)

Giải Đáp Kỹ Thuật

Câu Hỏi Thường Gặp (FAQ)

Những thắc mắc phổ biến nhất của các kỹ sư khi triển khai Vyen CLI.

Vyen được kiến trúc hoàn toàn bằng TypeScript chuẩn hóa sang 100% JavaScript thuần chạy trực tiếp trên Node.js (>= 22.16 LTS). Dự án không sử dụng bất kỳ thư viện C++ phụ thuộc native addons nào (Zero Native Addons). Nhờ đó, Vyen vận hành trơn tru trong thư mục người dùng ($HOME) của Termux mà không cần can thiệp quyền root hay cài đặt các môi trường giả lập proot nặng nề.
Thay vì phải trả mức phí cố định 20$/tháng cho các gói thuê bao độc quyền, Vyen cho phép bạn sử dụng API key cá nhân từ OpenAI, Anthropic, Gemini, Groq, hoặc kết nối miễn phí với các mô hình chạy cục bộ (Ollama, LM Studio). Bạn chỉ thanh toán chính xác lượng token thực tế sử dụng trực tiếp cho nhà cung cấp, giúp tiết kiệm từ 70% đến 90% chi phí.
Vyen tuân thủ nguyên tắc an ninh tối cao: khi xảy ra lỗi cú pháp cấu hình, timeout thực thi hook hoặc phát hiện script bên ngoài không rõ nguồn gốc, hệ thống lập tức từ chối quyền thực thi (Fail-Closed, exit code 2). Mọi script và thiết lập đều được kiểm chứng qua mã băm SHA-256 Workspace Trust, đồng thời tuyệt đối không rò rỉ API key ra môi trường shell con.
Khi gõ lệnh /pair trong phiên làm việc, Vyen khởi tạo một tunnel bảo mật qua Cloudflared và in ra mã QR ngay trong terminal. Bạn chỉ cần quét mã bằng camera điện thoại để mở giao diện Web UI điều khiển phiên agent từ xa. Kết nối được bảo vệ bởi token ngẫu nhiên 128-bit và áp dụng cơ chế ủy quyền an toàn.
Hoàn toàn có! Bạn có thể trỏ Vyen tới bất kỳ máy chủ tương thích OpenAI API nào đang chạy trên máy tính hoặc mạng LAN nội bộ (như http://localhost:11434/v1 với Ollama, hoặc LM Studio, vLLM). Quá trình suy luận diễn ra 100% offline, đảm bảo mã nguồn và dữ liệu mật của dự án không bao giờ rời khỏi thiết bị của bạn.
Vyen hỗ trợ chia tách nhiệm vụ phức tạp cho các Subagent chạy song song trong không gian làm việc độc lập. Đồng thời, cấu hình .vyen/mcp.json cho phép kết nối tức thì các máy chủ MCP (công cụ truy vấn database, GitHub, Brave Search, hệ thống tệp bên ngoài) với nguyên tắc bảo mật tối thượng: User Deny luôn có quyền ưu tiên cao nhất.
Không tìm thấy câu hỏi phù hợp với từ khóa đã nhập. Vui lòng thử từ khóa khác (ví dụ: termux, byok, pair, hook).
