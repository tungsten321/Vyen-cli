Termux First-Class

Tối Ưu Native Cho Termux Trên Android

Xây dựng bằng 100% JavaScript thuần chạy trên Node >= 22.16 LTS. Vận hành trực tiếp trong môi trường Termux mà không cần quyền root, không cần proot hay glibc wrapper cồng kềnh.

  • ✓ Khởi chạy tức thì trong thư mục $HOME của thiết bị di động
  • ✓ Tận dụng ripgrep hệ thống với cơ chế fallback JS thuần mượt mà
  • ✓ Hỗ trợ đầy đủ tương tác clipboard hệ thống Android
BYOK Freedom

Bring Your Own Key & Tự Do Đa Provider

Loại bỏ hoàn toàn chi phí thuê bao cố định và rủi ro bị khóa chặt vào một nhà cung cấp. Bạn toàn quyền sử dụng API key cá nhân để kết nối trực tiếp với các mô hình tiên tiến nhất.

  • ✓ Tương thích OpenAI, Responses API chuẩn mực và Anthropic Messages
  • ✓ Hỗ trợ suy luận cục bộ ngoại tuyến qua Ollama, vLLM, LM Studio
  • ✓ Tự động khám phá danh mục model linh hoạt qua lệnh /models
Fail-Closed Safety

Bảo Mật Phân Tầng & Workspace Trust

Quyền kiểm soát chặt chẽ với các chế độ Ask / Auto / Read-Only. Xác thực Workspace Trust bằng chữ ký SHA-256 bảo vệ toàn diện các kịch bản shell thực thi.

  • ✓ 8 Hook vòng đời fail-closed (PreToolUse, PostToolUse...) bảo vệ hệ thống
  • ✓ Ngăn chặn hoàn toàn việc rò rỉ credential API ra shell con
  • ✓ Nhật ký kiểm toán audit log định dạng JSONL minh bạch cục bộ
Extensible Power

Subagents & Model Context Protocol (MCP)

Khả năng mở rộng không giới hạn: phân quyền tác vụ cho các Subagent chạy nền độc lập, kết nối công cụ ngoài qua chuẩn Model Context Protocol (MCP) và ghép đôi thiết bị qua /pair.

  • ✓ Quản lý MCP cấp độ user và project (.vyen/mcp.json) với ưu tiên User Deny
  • ✓ Điều phối mạng lưới tác vụ Agent Network và workflow tùy biến
  • ✓ Ghép đôi thiết bị từ xa qua tunnel bảo mật Cloudflare (/pair)

Bắt Đầu Nhanh

Hướng Dẫn Cài Đặt Đa Nền Tảng

Hệ thống tự động phát hiện thiết bị hoặc bấm phím số 1-4 để chuyển đổi.

Quy trình cài đặt trên Termux (Android): Node.js >= 22.16 LTS 
# 1. Cài đặt các gói công cụ hệ thống cần thiết
pkg install nodejs-lts git bash ripgrep

# 2. Cài đặt Vyen CLI từ npm toàn cục
npm install -g @nguyenhuumanh/vyen

# 3. Khởi chạy wizard thiết lập tương tác
vyen setup
Quy trình cài đặt trên Linux (Debian, Ubuntu, Arch, Fedora): npm / pnpm / yarn / bun 
# Cài đặt Vyen toàn cục
npm install -g @nguyenhuumanh/vyen

# Chạy wizard tương tác thiết lập provider và model
vyen setup

# Bắt đầu làm việc
vyen
Quy trình cài đặt trên macOS (Apple Silicon / Intel / Darwin): Terminal / iTerm2 / Ghostty 
# Cài đặt Vyen toàn cục
npm install -g @nguyenhuumanh/vyen

# Cấu hình API key & chọn model
vyen setup

# Mở giao diện agent
vyen
Quy trình cài đặt trên Windows (PowerShell / Windows Terminal): PowerShell 7+ hoặc Windows PowerShell 
# Cài đặt Vyen trong PowerShell
npm install -g @nguyenhuumanh/vyen

# Chạy wizard hướng dẫn cấu hình
vyen setup

# Bắt đầu phiên làm việc
vyen

Minh bạch toàn bộ lộ trình kiến trúc, các cải tiến và kiểm toán bảo mật qua từng phát hành.

v0.5.0 Latest Release
Hiện tại · 2026-10

Chuẩn hóa Headless Contract (R1.4) & Tách Module src/events.ts

  • Bổ sung cờ --output-format stream-json|text với schema v1 có phiên bản chuẩn.
  • Hỗ trợ --json-schema <schema> ép kiểu Structured Outputs qua Ajv validator (cơ chế fail-closed).
  • Tách module src/events.ts quản lý tập trung toàn bộ Zod schemas và kiểu sự kiện headless.
  • Chuẩn hóa tài liệu token budget cho môi trường tự động hóa không giám sát.
v0.4.0 Major Architecture
2026-10

Lifecycle Hooks, Workspace Trust SHA-256 & Project MCP

  • Cấu hình phân tầng .vyen/settings.json với chính sách permissions.allow|ask|deny.
  • 8 sự kiện Hook vòng đời fail-closed (PreToolUse, PostToolUse, Stop, SessionStart...) bảo vệ an toàn hệ thống.
  • Xác thực Workspace Trust (--trust-workspace) bọc mã băm SHA-256 cho settings và kịch bản thực thi.
  • Hỗ trợ Project MCP (.vyen/mcp.json) theo quy tắc User Deny Wins.
  • Ghép đôi thiết bị từ xa qua Cloudflared (/pair) kèm QR và web UI điện thoại.
v0.3.1 Maintenance
2026-10

Lệnh Tự Nâng Cấp vyen upgrade

  • Lệnh vyen upgrade [VERSION] tự động nhận diện npm/pnpm/yarn/bun.
  • Hỗ trợ thông báo cập nhật bản mới một lần mỗi ngày trong TUI.
v0.3.0 Foundation
2026-10

Đại Tu TUI Siêu Tốc & Kiểm Toán Bảo Mật Toàn Diện

  • Render TUI tăng tốc ~80 lần mỗi frame; tối giản giao diện với thanh trạng thái tập trung.
  • Vá bảo mật: không lộ API key vào môi trường bash, rg, git.
  • Sửa lỗi xử lý chuỗi regex trong edit_file và apply_patch.
  • Nhật ký audit log JSONL cục bộ bảo vệ quyền riêng tư người dùng.
